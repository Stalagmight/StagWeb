Getting Started

How It
Works

01

Install StalagMight

Download and install the desktop application. Available for Windows, macOS, and Linux. Built with Tauri for native performance with a minimal footprint.

02

Import Your Data

Load DMP files directly from your mNemo device, or enter survey data manually through the built-in spreadsheet interface. Both paths lead to the same powerful analysis engine.

03

Organize & Analyze

Structure your surveys into sections. The system automatically detects loop closures and distributes errors across your network for maximum accuracy.

04

Visualize & Map

View your survey data as interactive 2D maps with satellite overlay. Zoom, pan, and inspect every station and leg in geographic context.

05

Export & Share

Generate publication-ready outputs in PNG, SVG, or PDF. Export raw data as CSV or JSON for integration with GIS tools or further analysis.
