Structural Integrity

Engineering decisions that separate Stalagmight from surface-level tools.

Data Architecture

Survey-Grade Precision

Built on a spatial database engine optimized for underground topology. Every measurement maintains full error metadata through processing.

  • Sub-centimeter coordinate precision
  • Full error propagation chains
  • Multi-datum coordinate transforms
  • Versioned survey datasets
Field Operations

Offline-First Design

Full functionality without connectivity. Sync when you surface. Conflict resolution handles concurrent underground survey sessions automatically.

  • Complete offline survey capability
  • Automatic sync on reconnect
  • Conflict-free replicated data types
  • Local-first storage architecture
Integration

Open Data Pipeline

Import and export in every standard speleological format. Direct GIS integration for surface-subsurface correlation.

  • Survex, Therion, Compass import
  • GPX/KML track alignment
  • GeoJSON/Shapefile export
  • REST API for custom pipelines
Security

Expedition Access Control

Granular permissions for sensitive cave locations. Protect endangered species data and restricted access sites.
