CS-00 — Core Samples

Everything you need to
map the underground

StalagMight processes raw survey data into navigable, shareable cave maps. Purpose-built for underwater cave exploration.

CS-01

DMP Import

Import survey data from mNemo dive computers. Automatic DMP parsing with validation and error reporting.

CS-02

Spreadsheet Entry

Manual data entry with a familiar spreadsheet interface. Input bearings, distances, depths, and station notes.

CS-03

2D Visualization

Interactive plan-view map with satellite overlay. Pan, zoom, rotate, and measure your survey network in real time.

CS-04

Section Management

Organize surveys into logical sections. Group, color-code, and toggle visibility for cleaner cartography.

CS-05

Loop Closure

Automatic closed-loop detection. Identify discrepancies and validate survey data integrity instantly.

CS-06

Multi-Format Export

Export to PNG, SVG, PDF for print-ready cartography, or CSV/JSON for analysis and collaboration.

Process

From raw data to finished map

Five steps from dive reel to publication-ready cartography.

Import

Load DMP files from mNemo or enter data manually in the spreadsheet

Organize

Group survey legs into named, color-coded sections

Visualize

See your network on an interactive 2D map with satellite overlay

Refine

Detect loops, review errors, and distribute corrections

Export

Generate PNG, SVG, PDF maps or CSV/JSON data files

Visualization

Interactive 2D survey maps

Navigate your entire cave system on a responsive canvas. Overlay satellite imagery for real-world geographic context.

  • Pan, zoom, and rotate with smooth controls
  • Satellite imagery overlay with opacity control
  • Color-coded sections and station labels
  • Real-time measurement tools
