Operations Sequence

Mission Protocol

The standard operating procedure from raw dive data to finalized cave map. Five phases, zero guesswork.

01

Data Acquisition

Connect mNemo devices and import DMP files directly into StalagMight. Alternatively, enter survey data manually through the built-in spreadsheet with real-time validation. All incoming data is parsed, verified, and indexed.

DMP Import mNemo Manual Entry Batch Processing
02

Section Organization

Group survey legs into logical cave sections. Assign names, color codes, and metadata to each passage. Build the structural framework of your cave system from independent dive trips.

Color Coding Branching Merge Trips
03

Loop Detection

The engine automatically identifies closed loops in your survey network. Review each loop's misclosure error, flag problem legs for re-survey, and validate the overall network consistency.

Auto-Detect Misclosure Vectors Flagging
04

Error Distribution

Apply least-squares error distribution across all detected loop closures. Watch accumulated errors dissolve as positional accuracy tightens across your entire cave network. Review residuals per station.

Least Squares Residual Analysis Network Tightening
05

Visualization & Export

Render your survey as an interactive 2D map with satellite overlay. Pan, zoom, annotate. Export finished maps as PNG, SVG, or PDF. Export data as CSV or JSON for downstream analysis and collaboration.

2D Map Satellite PNG SVG PDF CSV JSON

Operational Advantages

Field-proven advantages that set StalagMight apart for underwater cave survey teams.

Satellite Overlay

Georeference surveys and overlay on satellite imagery. See where underground passages relate to surface topography and access points.

Tauri + Rust Engine

Native desktop performance with a minimal footprint. Rust backend for computation, React frontend for a fluid, responsive interface.

Multi-Format Export

Deploy maps as high-res PNG, scalable SVG, print-ready PDF. Export raw data as CSV or structured JSON for analysis pipelines.

Multi-Team Merge

Combine survey data from multiple independent dive teams. Merge trips into a unified network with conflict detection and resolution.

Statistical Dashboard

Detailed metrics per section: total length, depth range, leg averages, misclosure percentages, error vectors, and network quality scores.

Offline-First Operations

No internet dependency. Process surveys in the field, at base camp, on the dive boat. All data stays local, secure, and under your control.
