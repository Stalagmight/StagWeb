Deployment Protocol

System Initialization Sequence

From project creation to first survey export in four operational phases.

01

Initialize Project

Create your project workspace, set coordinate reference system, and configure team access roles.

$ stalagmight init
02

Ingest Survey Data

Import existing cave surveys in Survex, Therion, or Compass formats. Upload GPS tracks and station coordinates.

$ stalagmight import *.svx
03

Process & Map

Run loop closure, generate passage walls, build 3D models. Add geological annotations and scientific observations.

$ stalagmight process --3d
04

Export & Share

Generate publication-ready maps and data exports. Share with team members or the wider speleological community.

$ stalagmight export --fmt svg
