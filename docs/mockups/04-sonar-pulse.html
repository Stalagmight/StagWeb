SCAN.MODULES

System Capabilities

Six core modules for processing underwater cave survey data from field collection through final export.

MOD.01 // IMPORT

DMP File Import

Direct ingestion of survey data from mNemo diving instruments. Automatic parsing of compass bearings, distances, and depth measurements from field expeditions.

MOD.02 // INPUT

Spreadsheet Entry

Manual data input through an integrated spreadsheet with full validation. Station names, compass bearings, tape distances, and inclination data entry.

MOD.03 // RENDER

2D Visualization

Real-time rendering of cave survey networks as 2D plan views with satellite imagery overlay. Pan, zoom, and inspect every passage connection.

MOD.04 // MANAGE

Section Management

Organize complex cave systems into hierarchical sections. Group survey legs, assign identifiers, and manage relationships between interconnected passages.

MOD.05 // DETECT

Loop Closure Detection

Automated identification of closed loops within the survey network. Essential for error analysis and validation of survey data integrity.

MOD.06 // ADJUST

Error Distribution

Least-squares adjustment engine distributes measurement discrepancies optimally across loop closures for maximum geometric accuracy.

PROTOCOL.SEQ

Operational Sequence

Five-phase workflow from raw field data to publication-ready cave maps.

01

Data Acquisition

Import DMP files from mNemo dive instruments or manually enter survey measurements through the integrated spreadsheet interface. All standard cave survey parameters supported.

INPUT PHASE
02

Section Organization

Structure your cave survey into logical sections and passages. Create hierarchies, name stations, annotate legs, and build the topology of your underwater cave network.

STRUCTURE PHASE
03

Loop Analysis & Correction

Automated loop closure detection identifies closed circuits in your survey. The least-squares engine then optimally distributes measurement errors across the entire network.

ANALYSIS PHASE
04

Visualization & Mapping

Render your corrected survey as a 2D plan view with optional satellite imagery overlay. Examine passage geometry, verify connectivity, and review the complete cave map.

RENDER PHASE
05

Export & Distribution

Generate outputs in PNG, SVG, or PDF for visual presentations and print-ready maps. Export structured data as CSV or JSON for analysis and collaboration.
