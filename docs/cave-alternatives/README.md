# Cave Theme Website Alternatives

Multiple website concept batches for the Stalagmight cave survey app, all grounded in the Cave color palette.

## Files

- `index.html`: gallery entry point linking all concepts
- `single-page-product-intro.html`: conventional single-page product introduction website
- `alt-01-basalt-ledger.html` ... `alt-10-expedition-dashboard.html`: individual concepts
- `standard-v2/`: 10 additional conventional one-page product intro alternatives
- `creative-v3/`: 10 higher-variance creative one-page product intro alternatives
- `shared.css`: shared Cave theme token baseline (mirrors `../Stalagmight/src/theme/tokens.ts` values)
- `shared.js`: simple reveal animation + footer year utility

## Local preview

From repository root:

```bash
python3 -m http.server 8080
```

Then open:

- `http://localhost:8080/docs/cave-alternatives/index.html`
