Windows

64-bit

Not code-signed yet. When SmartScreen says Windows protected your PC, choose More info → Run anyway.

macOS

Apple Silicon

  • Disk image.dmg

Apple Silicon (M1 and later) only — Intel Macs are not supported.

Not notarized yet, so macOS blocks the first launch. Clear the quarantine flag once:

xattr -dr com.apple.quarantine /Applications/Stalagmight.app

or allow it under System Settings → Privacy & Security → Open Anyway.
