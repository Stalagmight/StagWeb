Feature Highlights

Every Drip Refined

Built by cave divers, for cave divers. Every detail has been polished to crystalline clarity.

Satellite Overlay

Georeference your surveys and overlay them on satellite imagery. See exactly where passages run relative to surface features.

Tauri + Rust Core

Native performance with a lightweight footprint. The Rust backend handles computation while React delivers a fluid interface.

Multi-Format Export

Export maps as high-resolution PNG, scalable SVG, or print-ready PDF. Export raw data as CSV or structured JSON.

Collaborative Workflow

Merge surveys from multiple dive teams. Import and combine independent survey trips into a unified cave network.

Statistical Analysis

View detailed statistics for each survey section: total length, depth range, average leg length, misclosure percentages.

Offline-First Design

No internet required. Process surveys in the field, at base camp, or on the boat. Your data stays local and secure.
