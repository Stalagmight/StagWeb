# Your first project

> This is a sample page for testing the website's docs build. It is not real documentation.

1. Create a project.
2. [Import an mNemo file](../import/mnemo-dmp.md), and let the wizard
   [suggest where each section goes](../import/mnemo-dmp.md#the-suggest-step).
3. Check the [shots](../concepts/stations-and-shots.md#shots) in the table.
4. Plan the next dive with [gas reach](../planning/gas-reach.md).

> [!TIP]
> Everything you change can be undone, including an import.
