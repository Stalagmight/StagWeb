> This is a sample page for testing the website's docs build. It is not real documentation.

Every build is on the [releases page](/releases/).

| Platform | File | Notes |
|---|---|---|
| Windows | `.exe` or `.msi` | 64-bit |
| macOS | `.dmg` | Apple Silicon only |
| Linux | AppImage, `.deb`, `.rpm` | x86-64 |

## Windows

> [!NOTE]
> The installer is not code-signed yet. SmartScreen asks once; choose
> **More info**, then **Run anyway**.

## macOS

Open the disk image and drag Stalagmight to Applications.

## Linux

Make the AppImage executable with `chmod +x`, or install the package.

When it is installed, [start your first project](first-project.md).
